# Blog posts

Add a new `.md` file to this folder for each post. Files are sorted by `date` (newest first).

## Example

Create `2025-06-01-getting-started-with-modpacks.md`:

```md
---
title: Getting started with modpacks
date: 2025-06-01
---

## Introduction

HyPack makes it easy to build and share Hytale modpacks.

## Tips

- Start with a small set of mods
- Use **public** visibility to share with the community
```

The `title` and `date` fields in the frontmatter are required for best results. The filename (without `.md`) becomes the URL slug, e.g. `2025-06-01-getting-started-with-modpacks.md` → `/blog/2025-06-01-getting-started-with-modpacks`.
