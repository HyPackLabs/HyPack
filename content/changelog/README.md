# Changelog entries

Add a new `.md` file to this folder for each release. Files are sorted by `date` (newest first).

## Example

Create `2025-06-01-modpack-builder.md`:

```md
---
title: Modpack builder preview
date: 2025-06-01
---

## What's new

- Create modpacks from the nav **Create** button
- Search CurseForge mods

## Fixes

- Improved sign-in styling
```

The `title` and `date` fields in the frontmatter are required for best results. The filename (without `.md`) becomes the URL slug, e.g. `2025-06-01-modpack-builder.md` → `/changelog/2025-06-01-modpack-builder`.
